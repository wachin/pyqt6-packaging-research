# Windows packaging and antivirus notes

Lucio IVA Calculator now uses Nuitka as the official Windows build backend.

The older PyInstaller-based Windows packaging was kept in the `pyinstaller-old` branch for reference.

## Current Windows artifacts

The official Windows build generates:

```text
LucioIVACalculator-<version>-setup.exe
LucioIVACalculator-<version>-Windows-x64-portable.zip
```

Both artifacts are generated by:

```text
build/build_windows.ps1
```

and published by:

```text
.github/workflows/build.yml
```

## Why the project moved to Nuitka

The PyInstaller/NSIS Windows builds were legitimate, open source, and generated by GitHub Actions, but a few antivirus engines reported heuristic false positives. The detections were generic and most major vendors reported the files as clean.

Nuitka produced a different Windows binary layout because it compiles Python modules through a C/C++ compiler. In testing for version `0.1.1`, the Nuitka Windows artifacts received clean VirusTotal results:

- installer: `0/68`
- portable ZIP: `0/65`

## Current Windows build practices

The Windows build keeps these practices:

- no UPX compression;
- no administrator requirement for the installer;
- user-level installation under the current user's profile;
- application icon in the executable and installer;
- product/version metadata in the executable;
- product/version metadata in the NSIS installer;
- portable ZIP generated alongside the installer;
- installed app and portable app smoke-tested in GitHub Actions;
- SHA256 checksums generated for tagged releases.

## Files involved

```text
.github/workflows/build.yml
build/build_windows.ps1
build/requirements-windows.txt

scripts/compile_translations.ps1
```

## Remaining recommendation

Nuitka eliminated the observed VirusTotal detections for the tested Windows 0.1.1 artifacts, but code signing is still the strongest long-term way to improve Windows SmartScreen reputation and user trust.
